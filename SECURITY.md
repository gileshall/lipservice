# Security

## Reporting

Report a vulnerability privately: the "Report a vulnerability" button on the repository's
Security tab, or email security@lipservice.dev. Please do not open a public issue.

Say which version or commit, what you found, how to reproduce it, and what you think it allows.

## What is covered

- The engine, native and in the browser: its readers for text, SSML, scores and model files,
  the command line and the C interface.
- The Python package and its MCP server, including how model files are fetched and checked.
- The lipservice.dev site and its demos.

## Which versions get fixes

The latest release.
